Новый пользователь

Создаем отдельного пользователя для работы бота, типа не рекомендуется запускать процессы от root.

Пользователя называем gbotuser

adduser gbotuser

Надо ввести свой пароль для пользователя и не забыть его

дальше параметры можно просто прощелкать

Добавляем в группу sudo

usermod -aG sudo gbotuser

Проверяем через команду

groups gbotuser

Переключаемся на пользователя gbotuser с полной симуляцией его входа в систему

su - gbotuser

Обновление и апдейт

а также установка python

Обновляем пакеты системы и базовые утилиты

sudo apt update && sudo apt upgrade -y

Может попросить пароль пользователя

И занимает какое-то время

Устанавливаем Python

sudo apt install python3 python3-pip python3-venv -y

Перенос проекта

Создаем папку проекта

mkdir -p ~/gomeopathy_bot

и переходим в нее

cd ~/gomeopathy_bot

Создаем виртуальное окружение

python3 -m venv venv

source venv/bin/activate

Доступным образом копируем код проекта

git clone https://url-репозитория.git

Я скопировал через панель в MobaXterm

Устанавливаем необходимые библиотеки

pip install -r requirements.txt

Важно!!!

Если у вас в проекте нет файла requirements.txt, то создайте его

pip freeze > requirements.txt

Настройка запуска

Создаем службу

sudo nano /etc/systemd/system/g_bot.service

тут внезапно открывается редактор )))

вставляем в него

[Unit]
Description=Gomeopathy Bot Service
After=network.target

[Service]
User=gbotuser
WorkingDirectory=/home/gbotuser/gomeopathy_bot
ExecStart=/home/gbotuser/gomeopathy_bot/venv/bin/python3 g_bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target

Чтобы записать CTRL-O

Чтобы выйти CTRL-X

Надеюсь не надо объяснять что у всех будут указаны свои пути и свое имя файла

Запуск

Говорим systemd перечитать все файлы конфигурации служб

sudo systemctl daemon-reload

Запускаем нашу службу

sudo systemctl start g_bot

Разрешаем автоматический запуск нашей службы при каждой загрузке системы

sudo systemctl enable g_bot

Статус и логи

Статус работы бота

sudo systemctl status g_bot

выход q

Живые логи (ошибки, принты)

journalctl -u g_bot -f

выход CTRL-C
